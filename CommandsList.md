# Linux Commands

## File and folder navigation commands:
 | __Command__ | __Explaination__
```table
1.  ls      | List the content of a directory           |
2.  pwd     | Check a directory’s path                  |
3.  cd      | Change directory                          |
4.  locate  | Search for a file and its path            |
5.  find    | Find a file within the current directory  |
6.  rmdir   | Removes a directory only if it contains no files or subfolders | can also use rm -d []
7.  rm -r []| Deletes a directory along with all its files and subdirectories recursively | Options: -rf to ignore prompts and forcefully delete write-protected files or non-existent directories , -ri to receive a confirmation prompt before each file or subdirectory is deleted, providing an extra layer of safety, -rv to see a list of every file and directory as it is being removed
```
